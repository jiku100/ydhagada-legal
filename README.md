# 한 절 하가다 묵상 공개 안내 페이지

Google Play와 App Store 배포에 사용할 정적 웹페이지입니다. 앱 소스나 인증키 없이 개인정보처리방침, 계정 삭제 및 지원 정보만 포함합니다.

## 공개 전 필수 설정

`site-config.js`에서 아래 값을 실제 정보로 입력합니다.

```js
window.HAGADA_LEGAL_CONFIG = {
  appName: '한 절 하가다 묵상',
  operatorName: '스토어에 표시할 개발자 또는 운영 주체 이름',
  supportEmail: '앱 전용 공개 연락 이메일',
  effectiveDate: '2026년 9월 1일',
};
```

설정값이 비어 있으면 페이지에 배포 전 경고가 표시됩니다.

## 로컬 확인

저장소 루트에서 다음 명령을 실행한 뒤 브라우저에서 `http://localhost:4173`을 엽니다.

```sh
npx serve legal-site -l 4173
```

## 배포 권장 구조

이 폴더의 파일만 별도 공개 저장소로 옮겨 GitHub Pages에 배포합니다. 현재 앱 저장소와 환경 변수, Supabase 키, Firebase 파일은 공개 저장소에 포함하지 않습니다.

배포 후 스토어 등록 주소 예시는 다음과 같습니다.

- 지원 URL: `/index.html`
- 개인정보처리방침 URL: `/privacy.html`
- Google Play 계정 삭제 URL: `/account-deletion.html`

## 배포 전 운영 확인 사항

- 스토어 개발자 이름과 `operatorName`을 일치시킵니다.
- 실제 수신 가능한 전용 이메일을 사용하고 2단계 인증을 켭니다.
- 시크릿 브라우저와 모바일 네트워크에서 모든 URL이 로그인 없이 열리는지 확인합니다.
- 계정 삭제 페이지에 올바른 이메일 주소와 요청 양식이 표시되는지 확인합니다.
- 만 14세 미만 이용자가 직접 가입할 가능성이 있다면 보호자 동의 및 개인정보 처리 절차를 별도로 검토합니다.
- 교회명, 운영 주체 또는 데이터 처리 방식이 바뀌면 개인정보처리방침을 갱신합니다.

이 문서는 앱 구현을 기준으로 작성한 배포용 초안입니다. 실제 운영 주체와 적용 법령에 맞는 최종 검토는 배포 전에 진행해야 합니다.
